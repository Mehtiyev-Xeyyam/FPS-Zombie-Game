# FPS-Zombie-Game
Killing Zombies with AWP and zombies keeps spawning

There are 4 types of zombies and each has its own attack speed, HP, damage and speed.

Usefull things you may take:
-
  recoil script.
  zombies spawning script.
  or any other script(shooting, walking, zombie attacks etc..) 


and adjust them to your own project.

i did this game in just 5 hours. Dont judge it :D
